# Changelog

## 0.2.0
- Animated demo for every kettlebell exercise (open an exercise to see it loop).
- Optional video link per exercise: YouTube links embed in the card; .mp4/.gif links play inline.
  Without one, a "Find a video" link searches YouTube for that exercise.
- Animation picker in the session and library editors.
- Removed the daily calorie, protein and step targets.
